# MVLM 各分支：训练、推理参数与评测结果总览

整理时间：2026-11-12（北京时间），依据本地当前分支、Git 中其他本地分支记录及服务器实验汇总。**本表不是统一协议排行榜**：训练来源、初始化权重、数据划分、首帧规则和推理参数存在差别。AUC/PRE/NPR 均为百分数，AUC 通常逐视频等权平均；本地 OTB99-Lang 标准测试部分仅48条。没有证据的项目写“未核实”，不拿片段 IoU 或训练损失充当完整视频 AUC。

- **训练集**：用于优化参数；训练 loss/IoU 不等于在线跟踪精度。
- **留出验证集**：用于诊断、选择参数或检查点；若官方初始化权重可能见过这些视频，还需保留此限制。
- **测试集**：OTB 48、LaSOT 280、TNL2K 700（个别实验排除空语言）。在测试集上选参数/检查点属于探索性结果，不能再当作独立最终测试。
- 下文参数依次记为 `(α, τ, ω, λ, ψ)`，即 `ALPHA_CORR / TAU / OMEGA / LAMBDA / PSI_OUT`；联合模型另有 `QUALITY_WEIGHT`。参数与训练学习率不是同一概念。
- 历史单分支材料可在各 Git 分支对应文档或相应 worktree 查看，无法在当前分支找到的文件不代表原分支没有。

## 8. 读表时最重要的限制

1. 一张表中的同协议比较通常比跨表相减更可靠；标准测试、从训练集划出的验证和短片段不可混同。

3. 测试集搜索或按测试选检查点得到的最高值是探索性结果；冻结候选后需在未参与选择的数据上复核。
4. 原始目标涉及长时记忆；短片段训练及平均 AUC 尚不能证明遮挡后重现、长期记忆读取的实际作用。
