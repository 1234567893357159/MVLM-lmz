# 训练分析

1. 阅读 [训练指南](../../../REPRODUCTION.md)、[训练与结果记录](../../../REPRODUCTION.md)，再读取指定运行的配置、状态、日志和小型指标文件；按需查 `lib/train/` 与 `tracking/train_memory_world_tracker_b.py`。避免加载权重或扫描数据内容。
2. 确认阶段、初始化、冻结范围、代码版本、有效步数、batch、学习率调度、数据清单、日志口径及中断/恢复边界。分别观察 loss 分量、LR、梯度或显存（仅在有记录时）及验证趋势；检查 NaN、突变、缺失步、过拟合和欠拟合的证据。对比时先对齐预算和配置。
3. 将现象、可能原因和验证办法分开；不把相关性当成根因。片段验证 loss 最低不代表完整视频 AUC 最优；不存在的指标不可推断。优先提出只读检查或小规模验证，默认不启动训练。

输出：运行身份与证据、时间/步数趋势、异常与影响、按证据排序的假设、最小验证建议、未记录或尚未验证的内容。数值注明单位、范围及来源。

本分支资料入口：[README](../../../README.md)、[复现说明](../../../REPRODUCTION.md)；历史报告需核对日期、配置和适用范围。
