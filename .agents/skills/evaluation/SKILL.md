# 评测与比较

1. 阅读 [实验总览](../../../REPRODUCTION.md)、[实验索引](../../../REPRODUCTION.md) 和相关实验报告；按需核对 `tracking/test.py`、`tracking/analysis_results.py`、`lib/test/evaluation/`、`lib/test/analysis/` 及本分支适用的评测入口和配置。
2. 对每个结果核实代码版本、权重/初始化及哈希（如有）、配置和推理参数、数据集/划分/清单、序列数、首帧处理、坐标路径、指标计算、聚合方式、完成状态与结果文件。缺失标记未知；必要时核对逐序列状态、预测有效性和汇总，而不把部分运行当完整结果。
3. 对齐条件后才计算差值；不可对齐时列出差异而非断言优劣。区分标准测试、自定义留出与短片段，标明测试集选参/选检查点的探索性质，以及潜在训练数据重叠。结合具体脚本核实首帧和速度统计口径；勿将包含读图的计时直接称为纯模型 FPS。
4. 核对 AUC、PRE、NPR 的定义、单位与汇总，追溯数据来源。默认只做只读分析，不运行大规模评测或覆盖输出。

输出：可比性表（权重、数据、配置、协议、状态）、各指标与来源、可比较的差值及限制、缺失信息和最小验证建议。

本分支资料入口：[README](../../../README.md)、[复现说明](../../../REPRODUCTION.md)、[本分支研究记录](../../../reports/reproduction/RELIABLE_MEMORY_SMOKE_20261116.md)；历史报告需核对日期、配置和适用范围。
