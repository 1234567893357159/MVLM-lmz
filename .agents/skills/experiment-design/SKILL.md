# 实验设计

1. 阅读 [实验总览](../../../REPRODUCTION.md)、[实验索引](../../../REPRODUCTION.md)、[联合训练指南](../../../REPRODUCTION.md)，再核对相关 `experiments/mvlm/` 配置和训练/评测入口。现有记录是带日期的快照；先确认目标、可用资源及数据划分。
2. 写出可证伪假设、主指标和预期方向，设置同协议基线及逐项消融，固定初始化、数据、训练预算、种子与评测参数；说明每项改变和混杂因素。按需要考虑独立验证、多种种子、逐视频分析、耗时和资源预算。
3. 区分训练/验证/测试及来源重叠；测试集调参或选检查点仅为探索。世界模型、融合、CENTER、坐标路径及质量重排可能共同影响结果，避免把组合收益归因于单一模块；运行时关闭质量重排不等同去除质量头训练。长时记忆需有遮挡/重现等针对性证据。
4. 给出小规模预检、失败判据及记录路径，核实脚本参数和检查点兼容性。默认只规划，不启动长训或大规模实验；若资料不足，列明假设和待确认项。

输出：假设、对照/消融表、固定变量和变化变量、数据及协议、指标、资源与执行顺序、风险/限制、记录项和验证计划。

本分支资料入口：[README](../../../README.md)、[复现说明](../../../REPRODUCTION.md)、[本分支研究记录](../../../reports/reproduction/RELIABLE_MEMORY_SMOKE_20261116.md)；历史报告需核对日期、配置和适用范围。
