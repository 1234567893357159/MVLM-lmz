## 参数选择依据

- 阈值：固定原始其他参数时，TAU=0.0/0.03/0.06/0.1 的 AUC 分别为 58.95/59.30/58.33/56.48；这组比较支持保留 0.03。最佳邻域中改为 0.01 又降到 59.61。
- 干扰候选池：在组 1 基础上把 PSI_OUT 从 0 改为 0.1，AUC 从 59.30 到 59.69；在组 6 基础上提高到 0.2 则降到 59.21。不同上下文的结果不能简单视为全局规律。
- 分类信息：组 3 的 ALPHA_CORR 从 1.0 改为 0.7（加入 30% 分类差值），AUC 从 59.69 到 60.02。
- 历史记忆：组 3 同时提高 OMEGA/LAMBDA 到 0.6/0.7，AUC 降到 58.07；在组 5 基础上仅把 OMEGA 降为 0.2，AUC 小幅提高到 60.15。组 4 无法单独区分两个记忆参数的影响。

## 当前保留配置

```yaml
TEST:
  MVLM:
    ALPHA_CORR: 0.7
    TAU: 0.03
    OMEGA: 0.2
    LAMBDA: 0.4
    PSI_OUT: 0.1
```

相对原始基线，AUC/PRE/NPR 分别增加 3.67/4.37/5.03 个百分点。按完整测试集 AUC 选择配置，PRE 仅用于同分时比较。

这些结果来自 OTB 测试集上的自适应调参，说明发布权重对推理参数敏感，不能证明找回了作者的原始实验配置或解释全部复现差距。
每个配置只运行一次，没有多次重复或置信区间，尤其不能认定 0.13 个百分点等小差异一定稳定，也不能保证可迁移到其他数据集。
