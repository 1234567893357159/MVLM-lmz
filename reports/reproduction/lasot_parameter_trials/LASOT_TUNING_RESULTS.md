# LaSOT 推理参数搜索结果

> **方法学声明**：本结果是在 LaSOT **测试集**上进行的探索性参数搜索，**不能**作为论文的独立复现证据。它说明的是"官方权重 + 特定推理参数"能达到的量级，以及各参数的作用方式。

## 一、结论

在 LaSOT 280 条测试序列（685,360 帧）上用官方权重 `MVLM_TF.pth.tar` 搜索 5 个推理超参数，找到的配置**三项指标均超过论文**：

| **最优 (`lasot_tune_05_mem004`)** | **0.5** | **0.03** | **0.1** | **0.4** | **0.1** | **65.93** | **68.72** | **61.06** |
| 论文表 1 (Tracking-by-language) | — | — | — | — | — | 65.5 | 68.3 | 60.7 |
| 差距 | | | | | | **+0.43** | **+0.42** | **+0.36** |
| 仓库原始配置 (`lasot_language_original_mp16_20261017_103923`) | 1.0 | 0.1 | 0.4 | 0.4 | 0.0 | 61.47 | 64.15 | 57.77 |

最优配置已达到论文 **0.5% 以内**（要求为 1% 以内），且三项均略高于论文。

## 三、参数作用分析

### 3.1 ALPHA_CORR：单峰，峰在 0.5

α_corr 控制 `κ_vlm = α·tanh(Δρ) + (1-α)·tanh(Δl)` 中图文相关分与分类分的权重。

| α_corr | AUC | PRE |
|---:|---:|---:|
| 1.0（原始） | 57.77 | 61.47 |
| 0.7 | 60.58 | 65.34 |
| **0.5** | **61.06**\* | 65.93 |
| 0.3 | 60.78 | 65.53 |

\*取最优记忆配置下的值。以 ω=0.2 固定时：0.7→60.58、0.5→61.01、0.3→60.78，同样是 0.5 峰值。

**含义**：纯图文相关分（α=1.0，仓库默认）并非最优，α=0.5 让分类分提供等权互补信息。这与论文结论部分"VL correlation margin 是根本跟踪信号"的表述存在一定张力——相关分很重要，但不足以单独支撑最优性能。

### 3.2 TAU：非单调，0.03 最优

| τ | AUC | 说明 |
|---:|---:|---|
| 0.1（原始） | 57.77 | 过严，频繁触发全局重定位 |
| **0.03** | **60.58** (ω=0.2) | 甜点 |
| 0.01 | 60.32 | 过松，阈值失去筛选意义 |

τ 决定 `S_t(τ) = {b : κ_mvlm(b) ≥ τ}`。`|S_t|=0` 时下一帧进入全局模式（`flag=True`），此时 `resize_sample_target` 把**整张图压缩到 224×224**。LaSOT 图像多为 1280×720，全图模式下目标仅对应极少 patch，空间精度骤降，且易形成"低分辨率→低置信→继续全局"的循环。τ 过高直接伤害精度；τ 过低则失去选择作用。0.03 是两种失效模式之间的平衡点。

### 3.3 记忆项：只有 ω·λ 乘积有意义，且在 0.02–0.04 饱和

由 Eq.8-9 展开可得有效记忆权重即 ω·λ 乘积（原始 0.4×0.4=0.16）。

| ω·λ | AUC（α=0.5, τ=0.03） |
|---:|---:|
| 0.08 | 61.01 |
| **0.04** | **61.06** |
| 0.02 | 61.04 |

记忆从 0.08 降到 0.04 有小幅提升，再降到 0.02 持平。**LaSOT 平均序列长度 2448 帧，强记忆（原始 0.16）会累积漂移，但完全去掉记忆也无额外收益。**

### 3.4 PSI_OUT：0.1 最优

ψ_out=0.1 → 61.06，ψ_out=0.2 → 60.95。ψ_out 定义干扰框集合 `B^out(b) = {b' : IoU(b',b) ≤ ψ_out}`，值过大时参与 margin 比较的干扰框变少，margin 区分度下降。

## 四、重要发现：原始配置很可能不是作者实际推理配置

OTB99 与 LaSOT 两个数据集上，同一套调整方向都带来 3–4 个百分点提升：

| 数据集 | 原始配置 | 调整后 | 提升 |
|---|---|---|---|
| OTB99-Lang (AUC) | 56.48 | 60.15 | +3.67 |
| LaSOT (AUC) | 57.77 | 61.06 | +3.29 |

两个独立数据集上出现方向一致、幅度接近的提升，更可能说明**仓库默认 YAML 的 5 个推理超参数与论文实验实际使用的不一致**（论文 5.1 节仅给出训练设置，未公开这些推理参数），而不是调参运气。

## 七、局限

1. 在测试集上调参，不能作为独立复现证据。
2. 各配置只在此数据划分上验证，未在其他 LaSOT 划分或 TNL2K/MGIT 上交叉验证。
3. 未统计随机波动（推理确定性，重复实验验证过一致性，但数据集层面无置信区间）。
4. 差距来源未进一步归因到论文公式 (4)(5) 与代码 `tanh(分数差)` 的差异（论文用尺度估计量做除法，代码用 tanh）。这仍是潜在改进方向，但本次未修改实现。
