# MVLM 三数据集重新训练方案

日期：2026-10-30（北京时间）；分支：`codex/mvlm-reproduction`。用户随后授权正式训练与 W&B，并要求减少共享服务器资源占用。实际执行已调整为仅 GPU 4、5、每卡 batch 40、全局 batch 80；运行记录见 [正式训练记录](PAPER_REPRODUCTION_TRAINING_20261030.md)。实时状态以运行目录的 `training_status.json` 为准。

准备检查：4 项 CPU 回归检查通过；三套训练数据数量为 1,120 / 46,825 / 1,299，且只有指定异常 TNL2K 序列被过滤；真实读取和增强检查通过。原始准备报告保留了此前八卡配置的历史快照。随后单卡 3 步、四卡 4 步、最终两卡 2 步真实训练预检均通过，正式配置及审计冻结在运行目录。

目标是使用公开原始 MVLM 架构、论文训练数据与官方超参数重新训练。配置入口为 `experiments/mvlm/mvlm_TF_paper_reproduction.yaml`。不添加内容记忆网络或世界模型。初始化使用 FastITPN 预训练骨干和预训练 CLIP；语言投影层及 CENTER 预测头重新初始化，`MODEL.PRETRAINED_MODEL: null`，不载入官方训练好的 MVLM 或此前本地跟踪检查点。

## 依据及已知不确定性

- [论文第 3.2、5.1 节（作者上传全文）](https://www.researchgate.net/publication/408492697_MVLM_Template-Free_Tracking_via_Vision-Language_Margin_Confidence_and_Memory-Gated_Tracking)：三数据集、冻结 CLIP、60 轮、每轮 100,000 图文样本、AdamW、学习率 0.0005、batch 80、4 张 A6000 48GB。
- [官方 YAML](https://github.com/inha-vllab/MVLM/blob/main/experiments/mvlm/mvlm_TF.yaml)：补充 1:1:1 抽样、增强、编码器学习率倍率、权重衰减及学习率日程。仓库原始快照为 `original_config.yaml`；当前 `mvlm_TF.yaml` 的 TEST 部分包含历史调参值，不直接用作本次配置。
- **batch 的论文含义未公开明确**：论文写 80，但未说明全局或每卡；官方加载器按每进程 80 读取，4 卡直接运行是全局 320。本方案选择“全局 80”作为明确的复现假设，不声称作者一定采用这个含义。按用户最新共享服务器资源要求，正式配置为 2 卡 × 每卡 40；不能把它标为与官方四卡启动完全等价。若后续研究官方代码启动语义，应另立全局 320 的对照，保留其不同更新步数。
- 最初考虑八卡，实际发现 GPU 0–3 被其他任务占用。用户先选择空闲四卡，再要求进一步减少资源占用，因此通过短测后只使用 GPU 4、5，保留 GPU 6、7 空闲。CENTER 的 BatchNorm 统计可能随每卡 batch 改变；不因为全局 batch 相同就宣称不同卡数严格等价。
- 论文没有充分公开随机种子、实际初始化映射等细节，本方案保存实际源码、权重及数据清单哈希，不能承诺重现到完全相同分数。

## 数据方案

| 数据集 | 本地训练序列 | 使用方式及差异 |
| --- | ---: | --- |
| LaSOT | 1,120 | 仓库 `lasot_train_split.txt` 的标准训练划分，测试集不参与训练 |
| VastTrack | 46,825 | 使用完整本地可用 `vasttrack_train_split.txt`；已排除 11 条镜像缺帧序列 |
| TNL2K | 1,299 | 保留 1,300 条源数据，训练过滤 `Fight_game_004-Done`，其 957 张图像与 816 行框标注不匹配 |

抽样先以 1:1:1 概率选择数据集，再按原采样器选择视频及帧。总计每轮 100,000 次采样，60 轮约 600 万次，各数据集期望约 200 万次，不要求每轮精确等分。

TNL2K 排除项显式保存在 `DATA.TRAIN.TNL2K_EXCLUDE_SEQUENCES`，通过 `update_settings()` 和 `names2datasets()` 传至训练数据集，过滤发生在数据比例抽样前。默认配置也跳过该已知异常项。源目录、压缩包和测试集都不删除或改写。原数据准备状态仍可能报告 1,300 条完整源集验证失败；这与排除后 1,299 条用于训练是两个不同状态，不能覆盖源集错误报告。

TNL2K 现有官方修订标注记录和 `monitor_manypeople_train` 重命名记录需要随实验保存，见 `downloads/official_training/tnl2k_annotation_revisions.json` 和 `tnl2k_sequence_renames.json`。下载哈希匹配第三方镜像，不等于已证明与作者原始档案逐字节一致。

本轮使用全部 46,825 条可用 VastTrack 序列，以尽量保留训练数据。此前 VastTrack-only 实验留出的 500 条也将参与本轮训练；它们之后不能再作为本轮独立验证集。主实验固定评测第 60 轮，不按测试成绩挑选 epoch。若以后需要验证选模型，应另立事先冻结的视频级划分，并说明训练集减少的差异。

## 固定训练参数

| 项目 | 本次设置 |
| --- | --- |
| 视觉骨干 / 文本编码 | FastITPN-Base / CLIP ViT-L/14 |
| 训练范围 | 冻结 CLIP 本体；训练视觉编码器、语言投影和 CENTER |
| 搜索图像 / stride | 224×224 / 16，196 个视觉 token |
| 文本 | 完整 77 token，投影至 512 维 |
| 搜索裁剪 | factor 4.0，中心扰动 3.5，尺度扰动 0.5 |
| 模板配置 | 保留官方 112×112、factor 2.0、数量 1；模型 `TEMPLATE_FREE=True`，编码器不拼入视觉模板 |
| 数据增强 | 沿用官方灰度、水平翻转、颜色扰动与 ImageNet 归一化实现 |
| 每卡 / 全局 batch | 40 / 80，2 个 DDP 进程，物理 GPU 4、5，无梯度累积 |
| 每轮 / 总轮数 | 100,000 样本 / 60 轮；每轮 1,250 次更新，共 75,000 次 |
| 优化器 | AdamW，weight decay 1e-4 |
| 学习率 | CENTER 5e-4；原实现按名称归入编码器组的视觉骨干和语言投影 5e-5 |
| 学习率日程 | StepLR，第 54 轮结束衰减 0.1，后 6 轮使用衰减后学习率 |
| 损失 | 2×GIoU + 5×L1 + Focal + 0.5×CM |
| 梯度裁剪 / Drop path | 0.1 / 0.1 |
| 精度 | 沿用当前官方训练路径 FP32，不引入 AMP、EMA 或新损失 |
| 随机种子 | 当前训练入口实际固定 1234567890，分布式加 local rank；论文未明确该值 |
| DataLoader workers | 每进程 2，总计 4 个，减少共享 CPU 和磁盘压力；计算线程每进程 1 个 |
| 保存与监控 | 每轮保存检查点、优化器、global_step；W&B 在线监控，仅 rank 0 上传跨卡平均指标 |

## 执行顺序

1. 按用户要求缩短预检：单卡 batch 20 仅 3 步；四卡 batch 20 仅 4 步；资源方案调整后两卡 batch 40 仅 2 步。已核对损失及保存权重有限、CLIP 冻结、骨干/投影/头实际更新。所有预检输出独立保存，预检权重不进入正式训练。
2. 预检通过后冻结源码、配置、GPU/有效 batch、数据清单顺序及 SHA256、排除项、权重哈希和初始化报告。启动前确认 GPU 4、5 空闲；不终止或占用其他用户现有任务所在的 GPU 0–3。
3. 新建正式输出目录，从预训练骨干及 CLIP 重新初始化，训练 60 轮。当前训练器会自动寻找输出目录中的旧检查点，所以独立重训必须使用此前不存在的目录。恢复同一次中断实验时才复用原目录；epoch 级恢复不声称逐步位级复现。
4. 固定第 60 轮检查点，先使用官方发布 TEST 参数和标准测试入口完成 OTB99-Lang 48 条、LaSOT 280 条、TNL2K 700 条评测。TNL2K 既有测试空语言问题保留并记录，不能把 699 条与 700 条混为同协议。另用相同权重运行已有严格首帧语言定位入口作为补充，保留其排除项和独立协议标签；不可将两个入口的成绩混用。MGIT 数据尚未准备，不宣称四个基准的完整复现。
5. 官方公开权重用相同配置和协议作为对照；报告 PRE/NPR/AUC、逐序列完整性及协议。主结果不沿用测试集调参最优配置，也不根据测试分数搜索本轮超参数。

正式训练由独立监督进程在冻结源码中启动，实际命令保存在运行目录的 `supervisor_launch.json` 和 `training_status.json`。查看现状：

```bash
cat /root/MVLM/output/paper_reproduction_20261030_run01/training_status.json
tail -n 20 /root/MVLM/output/paper_reproduction_20261030_run01/train.log
```

训练耗时待三数据集预检后根据实际吞吐估计；以前 VastTrack-only 的耗时只能作为历史参考。本方案尽量对齐公开设置，但存在数据排除、batch 含义、硬件与评测实现等明确差异，实验报告需要全部保留。
