# B 模型与原始基线：历史 OTB 参数迁移实验

2026-11-12，探索性实验。将历史官方权重 OTB 测试集调参得到的一组参数固定迁移到基线、B1025 和 B4000，三组都使用相同参数、OTB99-Lang 本地 48 条完整视频和原评测首帧 GT 计分口径。B1025 根据留出片段 loss 选出，B4000 为预定终点。本实验使用了同一测试集上过去选出的参数，不是独立最终测试，不能据此反复调参并声称独立精度。

| 参数 | 原对照配置 | 历史 OTB 参数 |
|---|---:|---:|
| ALPHA_CORR | 1.0 | 0.5 |
| TAU | 0.1 | 0.03 |
| OMEGA | 0.4 | 0.4 |
| LAMBDA | 0.4 | 0.1 |
| PSI_OUT | 0.0 | 0.1 |

历史参数来自 [OTB 参数搜索记录](otb_parameter_trials/OTB_TUNING_RESULTS.md) 的 `otb_tune_03_prod04_c`；历史最优并非官方作者明确提供的参数。本次同时变化五项参数中的四项，只能比较组合效果，不能归因于单个参数。模型代码、权重和其他参数沿用[原三组测试](MEMORY_WORLD_B_VIDEO_ANALYSIS_20261112.md)。

| 模型 | 原配置 AUC / PRE / NPR | 历史参数 AUC / PRE / NPR | AUC 变化 |
|---|---|---|---:|
| 官方权重基线 | 56.84 / 79.38 / 70.02 | 60.58 / 83.95 / 75.05 | +3.73 |
| B1025 | 56.28 / 78.66 / 68.75 | 57.63 / 80.05 / 71.24 | +1.36 |
| B4000 | 55.54 / 77.61 / 67.48 | 58.89 / 81.73 / 72.80 | +3.35 |

历史参数下 B1025 与 B4000 相对同参数基线 AUC 分别为 -2.94、-1.68；较原配置分别为 -0.57、-1.30。因此历史参数提升了三个模型的绝对成绩，但未消除联合模型相对基线的 OTB 差距。参数会影响可靠候选筛选、局部/全局搜索与记忆写入；当前实验未记录足够中间状态，不能判定具体因果机制，也不能推广到 LaSOT 或 TNL2K。

新脚本 `tracking/evaluate_memory_world_otb_historical_params.py` 使用独立输出目录 `output/memory_world_b_otb_historical_params_20261112_run01/`；包含模型哈希和参数的 `manifest.json`、逐视频预测、状态、日志及 `summary.json`。三组各 48 条完整完成；先对三模型各跑 Biker 前40帧短测。GPU 测试结束后已释放。没有修改原权重、配置或上次评测结果。
