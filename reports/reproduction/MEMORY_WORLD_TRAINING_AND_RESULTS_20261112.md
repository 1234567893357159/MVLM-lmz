## 2. 模型流程

```text
图像 + 语言 ──> MVLM 特征提取 ──> 当前视觉特征 ──┐
                                                   ├─> 融合 ─> 定位头 ─> 质量重排 ─> 目标框
历史观测 ──> 内容记忆库 ──> 世界模型 ──> 未来预测 ─┘                         │
     ▲                                                                         │
     └─────────────────── 原始视觉 ROI 与预测框更新历史 ───────────────────────┘
```

每个视频单独维护记忆和历史。世界模型利用历史观测、内容记忆与语言预测未来信息；质量头辅助候选框选择。写入记忆的是定位后提取的原始视觉 ROI，不是预测生成的特征。GT 用于训练监督，不用于 B 阶段或测试时的定位和记忆写入。

## 3. 数据与采样

使用 LaSOT、VastTrack、TNL2K 的训练视频，来源按 **1:1:1 的概率**采样，再在对应来源内按视频均匀采样；这不是按三个数据集的原始视频数量等比例采样。

| 来源 | 训练视频数 | 留出验证视频数 |
|---|---:|---:|
| LaSOT | 1008 | 112 |
| VastTrack | 41082 | 4565 |
| TNL2K | 1169 | 130 |
| 合计 | 43259 | 4807 |

清单位于 `output/memory_world_split/manifest.json`，按视频隔离训练与留出验证。已知异常序列和不足 12 帧的视频按清单记录排除；路径和标注元数据检查不等于逐张图像内容去重。官方初始化权重可能已经见过适配时留出的训练视频，留出集用于训练诊断与模型选择，完整测试另行报告。

每个片段 12 帧，前 4 帧用于建立历史，后 8 帧按有效标注条件提供监督；片段内采样间隔为 1～4。历史与记忆状态不跨片段反向传播，片段互不共享状态。

## 4. A 阶段：训练预测模块

| 项目 | 实际设置 |
|---|---|
| 显卡 | 2 张 RTX 3090，物理 GPU 0、1 |
| 批量 | 每卡 256 个片段，全局 512；无梯度累积 |
| 更新 | 4000 步，正常完成 |
| 训练模块 | 记忆读取器、世界模型、候选质量头，共 2,908,167 个可训练参数 |
| 冻结模块 | 视觉与文本编码器、CENTER 定位头、融合层 |
| 优化 | AdamW，学习率 `1e-4`，weight decay `1e-4`，cosine 至 0，梯度范数上限 `1.0` |
| 精度 | 视觉编码器及新增模块 FP32，冻结 CLIP 沿用其库的 CUDA 加载精度 |
| 损失 | 外观 + 运动 + `0.5 ×`质量；外观特征回归内部权重 `0.1` |
| 历史 | 前 1000 步预测历史比例由 0 增至 0.5，验证全部使用预测历史 |
| 验证 | 固定 32 片段，每 50 步验证和保存 |

A 第 3000 步是当前 B 的父权重：`output/memory_world_stage_a_2gpu_20261109_run02/step_003000.pth.tar`。A 的输出、配置和详细运行记录见 [A 阶段训练记录](MEMORY_WORLD_STAGE_A_20261109.md)；实际完成状态以对应输出目录下 `training_status.json` 为准。

## 5. B 阶段：完整跟踪器适配

最早试验的 B 只训练融合层，视觉主干虽然在显卡上但不保留反向图，因此 batch 80 显存占用仅约 3717 MiB/卡；该试验已停止，不是下面的正式 B。

| 项目 | 实际设置 |
|---|---|
| 初始化 | 官方 MVLM 权重 + A 第 3000 步权重，不继承旧 B |
| 显卡与 batch | 2 张 RTX 3090，物理 GPU 2、3；每卡 40 个片段，全局 80 |
| 显存与精度 | 两卡实测峰值约 22243 MiB/卡；FP32，逐帧反向释放计算图 |
| 更新 | 4000 次优化器更新，正常完成；12 帧中前 4 帧预热，后 8 帧按有效帧监督 |
| 训练模块 | 视觉编码器、CLIP 输出语言投影、CENTER 定位头、未来融合层；共 90,100,230 个可训练参数 |
| 冻结模块 | CLIP 本体、A 得到的记忆读取器、世界模型及质量头 |
| 学习率 | 编码器/语言投影 `1e-5`；CENTER `5e-5`；融合层 `1e-4` |
| 其他优化设置 | AdamW、weight decay `1e-4`、cosine 4000 步至 0、梯度范数上限 `0.1` |
| 验证 | 初始及每 25 步固定 96 个片段；使用预测历史 |

损失为 `L_B = 2 × GIoU + 5 × L1 + focal + 0.5 × CM`。每个优化步逐帧累积梯度，不对历史帧进行跨帧反向传播。两卡训练参数一致，预期模块有更新，冻结参数未变化；本地日志未发现 NaN、无穷大或跳过批次。

训练 loss 前 100 步均值约 `1.0592`，第 1951～2050 步约 `0.6944`，第 3901～4000 步约 `0.6842`。训练逐步下降，但单批视频难度不同使单步值波动。固定片段验证也会受预测裁剪及有效监督帧数量变化影响，不能把一次的 loss 当作完整视频跟踪精度。

检测头 BN 运行统计每个训练步随 12 帧前向被更新，包含预热帧。替换统计量对早期验证结果有明显影响，但后期并非总能改善，因此它是值得进一步对照的因素，不能将全部波动都归因于它。详细诊断和训练范围见 [B 阶段训练记录](MEMORY_WORLD_TRACKER_B_20261111.md)，完整本地曲线见 [loss 曲线](memory_world_tracker_b_20261111/observed_curves.png)。

固定 96 片段的诊断：对预热后全部 731 个可见且标注有效帧，统计最终选择的整图框：

| 权重 | 平均 IoU | IoU ≥ 0.5 的帧比例 | 裁剪内验证 loss |
|---|---:|---:|---:|
| B 初始化（A 第 3000 步） | 0.7186 | 78.66% | 1.3222 |
| B 第 1025 步 | 0.7391 | 80.85% | 1.0205 |
| B 第 4000 步 | 0.7278 | 80.44% | 1.0558 |

这只是短片段诊断，不是完整视频在线测试。不同检查点的裁剪内有效监督帧会变化，loss 与整图 IoU 也不完全等价。配对重采样区间覆盖零，不能仅凭这组数据断定收益稳定。

训练数值和资源记录在 `output/memory_world_tracker_b_2gpu_b80_20261111_run01/` 和对应 setup 目录。W&B 原运行 [zovlqxy8](https://wandb.ai/2896287267-hit/mvlm-reproduction/runs/zovlqxy8) 因网络/代理问题远端只收到约第 100 步并显示 crashed；这是监控同步状态，实际训练已完成 4000 步，以本地日志和状态文件为准。
